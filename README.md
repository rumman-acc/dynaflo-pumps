# Dynaflo, Inc. — Website

This is a single-page marketing website for Dynaflo, Inc., a manufacturer of custom energy-efficient mini diaphragm vacuum pumps and air compressors based in Reading, Pennsylvania.

## Overview

This website is built as a single, self-contained `index.html` file with all CSS inline. It requires no build process, external frameworks, or dependencies beyond Google Fonts for typography.

## Features

- Fully responsive design optimized for desktop, tablet, and mobile devices
- Accessible HTML with semantic markup and proper ARIA considerations
- Sections covering company overview, products, differentiators, and contact information
- Sticky header for easy navigation
- Modern, professional design with Dynaflo's brand colors

## Deployment

To deploy this website:

1. **Static Hosting**: Upload the `index.html` file to any static web hosting service:
   - GitHub Pages: Push to a repository and enable Pages
   - Netlify: Drag and drop the file to Netlify's dashboard
   - Vercel: Import the repository or upload the file
   - AWS S3: Upload to an S3 bucket configured for static website hosting
   - Traditional web hosting: FTP the file to your web server's public directory

2. **Local Testing**: Simply open `index.html` in any modern web browser

No server-side processing, build steps, or dependencies are required.

## Technical Details

- Single HTML file with inline CSS
- Web fonts loaded from Google Fonts CDN
- No JavaScript required
- No external images or assets
- Fully self-contained and portable
